# Calculadora Web (Dark/Light Mode)

Uma calculadora minimalista e responsiva desenvolvida com HTML, CSS e JavaScript puros. O projeto foca em boas práticas de UI/UX, utilizando CSS Grid para layout e Variáveis CSS para gerenciamento de temas.

## ✨ Funcionalidades

- Operações matemáticas básicas (adição, subtração, multiplicação, divisão).
- Alternância entre tema Escuro (padrão) e Claro com transições suaves.
- Layout responsivo utilizando CSS Grid.
- Arquitetura limpa com separação clara de estrutura, estilo e lógica.

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estrutura semântica.
- **CSS3**: CSS Grid, Variáveis CSS (Custom Properties) para temas, Flexbox.
- **JavaScript (ES6+)**: Manipulação do DOM, gerenciamento de estado e eventos.
